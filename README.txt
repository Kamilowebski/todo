Lista zadań (Supabase)

1. zadania.sql  -> wklej w Supabase (SQL Editor) i uruchom
2. zadania.html -> uzupełnij SUPABASE_URL i SUPABASE_ANON_KEY na górze skryptu
3. Wrzuć na GitHub Pages: zadania.html, manifest.webmanifest i folder ikony/ (w jednym katalogu)
4. Konta zakładasz ręcznie w Supabase: Authentication -> Users -> Add user
   (zaznacz Auto Confirm User). Opcjonalnie wyłącz rejestrację:
   Authentication -> Sign In / Providers -> wyłącz "Allow new users to sign up".
